# Vivinati

Buscador de inmuebles de Venezuela — **https://vivinati.com**

- `site/` — la web (HTML, CSS y JavaScript estáticos; se publica en GitHub Pages).
- `scripts/indexador/` — indexador de anuncios de otras webs (GitHub Actions, cada 6 h).
- `scripts/seo/` — páginas para Google, sitemap y precios por zona (en cada despliegue y a diario).
- `scripts/alertas/` — correos diarios de alertas de búsqueda (Resend).
- `supabase/` — cambios de la base de datos (SQL) y plantillas de correo.
- `.pages.yml` — editor de contenido (Pages CMS).
